# Noesis Product Blueprint

## Mission

Noesis turns thought into understanding.

It helps a person move from something encountered to something understood, tested, expressed, and revised without losing the path that produced it.

## Core Intellectual Loop

1. **Sources** hold books, articles, recordings, films, conversations, and other material.
2. **Annotations** preserve excerpts and the user's interpretation in source context.
3. **Concepts** clarify the vocabulary recurring across those materials.
4. **Inquiries** organize uncertainty into evidence, assumptions, candidate answers, and unknowns.
5. **Positions** record claims the user is prepared to examine, challenge, and revise.
6. **Practices** test positions and inquiries through lived action and observation.
7. **Works** let the user express, synthesize, and create without forcing every artifact into an argument template.
8. **Evolution** records consequential changes as an intellectual history.
9. **Atlas** reveals the structure of the system without inventing beliefs or replacing the underlying records.

Every promoted object must retain provenance. Every meaningful mutation must write a factual thinking event. Suggestions and derived views must remain visibly distinct from user-authored records.

## Product Principles

- Complexity belongs in the system, not in the user's path.
- Empty, loading, failed, demo, derived, and user-authored states are never interchangeable.
- The user owns every accepted claim and decides when uncertainty becomes a position.
- Practices produce evidence only after observations are logged.
- Works prioritize creative production; connections and diagnostics remain secondary.
- Evolution records meaningful intellectual movement, not routine interface activity.
- Atlas organizes real entities and relationships; it does not fabricate a philosophy.
- AI assistance is optional, manually invoked, item-first, bounded, and reviewable.

## Experience Standard

- Dark editorial surfaces with high legibility and consistent semantic theme tokens.
- Clear page ownership, progressive disclosure, and one dominant action per state.
- Persistent provenance and reliable user-scoped storage.
- Keyboard, touch, mobile, and assistive-technology access for every core workflow.
- Fast route changes with the shell remaining visible while page content loads.
